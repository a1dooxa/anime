# anime

Терминальный плеер аниме с русской озвучкой для macOS: поиск → серия → озвучка → просмотр в [IINA](https://iina.io).

- Ищет сразу по нескольким источникам (yummy-anime, animego) через [anicli-api](https://github.com/vypivshiy/anicli-api), а сайты студий (AniDUB и др.) опрашивает уже на шаге выбора озвучки.
- Одна студия под разными названиями показывается одной строкой.
- Сам выбирает рабочий плеер: проверяет поток до запуска и, если IINA не стартовала за 15 секунд, ставит следующий.
- Kodik идёт через локальный прокси (`kproxy.py`, только `127.0.0.1`): он держит соединения, повторяет потерянные запросы и подкачивает сегменты заранее. Помогает в сетях, где до CDN kodik теряются соединения.
- Помнит историю: последний тайтл, серию и озвучку.

## Установка

Нужны macOS, Python 3.12+, [Homebrew](https://brew.sh).

```bash
brew install fzf ffmpeg
brew install --cask iina
git clone https://github.com/a1dooxa/anime.git ~/anime
cd ~/anime
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
ln -s ~/anime/bin/anime /usr/local/bin/anime
```

`ffmpeg` нужен только для замера `coverage.py`.

## Запуск

```bash
anime                  # меню: история и поиск
anime фрирен           # сразу искать
anime --selftest       # быстрые проверки без сети
```

Выбор стрелками в fzf, `Esc` — назад.

## Файлы

| файл | что делает |
|---|---|
| `anime.py` | CLI: поиск, серии, озвучки, выбор плеера, запуск IINA |
| `anidub.py` | парсер anidub.com |
| `kproxy.py` | локальный HLS-прокси для kodik, сам выключается после 3 часов простоя |
| `coverage.py` | замер: какие серии реально играют и сколько ждать до видео, пишет отчёт в `reports/` |

Личные данные (`history.json`, `events.jsonl`, `reports/`) лежат рядом с кодом и в git не попадают.

## Оговорка

Проект только находит ссылки на видео на сторонних сайтах и открывает их в плеере; сам он ничего не хранит и не раздаёт. Доступность источников зависит от вашей сети и страны.
