# 🎬 anime

**Аниме с русской озвучкой прямо из терминала.** Набрал название, выбрал серию и озвучку, и серия уже идёт в [IINA](https://iina.io). Без браузера, рекламы сайтов и поиска рабочего плеера.

```
🔎 поиск  →  🎬 тайтл  →  📺 серия  →  🎙 озвучка  →  ▶️ IINA
```

## ✨ Что умеет

- 🔎 **Быстрый поиск** сразу по yummy-anime и animego через [anicli-api](https://github.com/vypivshiy/anicli-api). Сайты студий (AniDUB и др.) опрашиваются уже на шаге выбора озвучки, поэтому поиск не ждёт медленные сайты.
- 🎙 **Все озвучки в одном списке.** AniLibria, AniDUB, StudioBand и другие; одна студия под разными названиями показывается одной строкой.
- 🛟 **Сам находит рабочий плеер.** Проверяет поток до запуска, а если IINA не стартовала за 15 секунд, ставит следующий.
- 🚀 **Kodik без подвисаний.** Kodik идёт через встроенный локальный прокси (`kproxy.py`, только `127.0.0.1`). Прокси держит соединения, повторяет потерянные запросы и подкачивает сегменты заранее.
- ⏭ **Быстрая смена серий.** Следующая серия открывается в том же окне IINA за 2–6 секунд.
- 🧠 **Помнит, где ты остановился.** Последний тайтл, серию и озвучку.

## 📦 Установка

Нужны 🍏 macOS, 🐍 Python 3.12+ и 🍺 [Homebrew](https://brew.sh).

```bash
brew install fzf ffmpeg
brew install --cask iina
git clone https://github.com/a1dooxa/anime.git ~/anime
cd ~/anime
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
ln -s ~/anime/bin/anime /usr/local/bin/anime
```

`ffmpeg` нужен только для замера `coverage.py`.

## ▶️ Запуск

```bash
anime                  # 📜 история и поиск
anime фрирен           # 🔎 сразу искать
anime --selftest       # ✅ быстрые проверки без сети
```

⌨️ `↑↓` выбрать · `Enter` ок · `Esc` назад · печатай, чтобы фильтровать

## 🗂 Файлы

| файл | что делает |
|---|---|
| 🎬 `anime.py` | CLI: поиск, серии, озвучки, выбор плеера, запуск IINA |
| 🎙 `anidub.py` | парсер anidub.com |
| 🚀 `kproxy.py` | локальный HLS-прокси для kodik, сам выключается после 3 часов простоя |
| 📊 `coverage.py` | замер: какие серии реально играют и сколько ждать до видео, отчёт в `reports/` |

🔒 Личные данные (`history.json`, `events.jsonl`, `reports/`) лежат рядом с кодом и в git не попадают.

## ⚠️ Оговорка

Проект только находит ссылки на видео на сторонних сайтах и открывает их в плеере. Сам он ничего не хранит и не раздаёт. Доступность источников зависит от твоей сети и страны.
